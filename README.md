# Karen
AI Karen — голосовой ассистент с лицом-монитором.

```
pip install edge-tts pygame SpeechRecognition pyaudio google-genai
GEMINI_API_KEY=... python Karen.py
python face.py        # демо лица: 1-6 эмоции, пробел — «говорит», t — «думает»
```

### На Raspberry Pi с 7" DSI-экраном (800×480)

```
KAREN_FULLSCREEN=1 KAREN_BEZEL=0 python Karen.py
```

`KAREN_FULLSCREEN=1` — на весь экран в родном разрешении, без курсора; `KAREN_BEZEL=0` — без нарисованной рамки монитора. Выход — Esc или «стоп». Звука у DSI-экрана нет: нужны USB-микрофон и колонка (USB или 3.5 мм).

## Эмоции

Gemini ставит тег эмоции перед предложением (`[angry] Опять ты...`). Тег не озвучивается, а лицо меняется в момент, когда начинает звучать это предложение. Через 3 с после ответа лицо возвращается к волне.

| лицо | когда |
|---|---|
| волна | спокойное состояние; качается в такт её голосу и голосу собеседника, бегущий импульс — «думает» |
| `happy` | рада, смешно |
| `angry` | злится, раздражена |
| `bored` | скучно; включается само, если собеседник говорит дольше 6 с (`BORED_AFTER`) |
| `surprised` | удивлена; также при ошибке |
| `sad` | грустно, сочувствует |
